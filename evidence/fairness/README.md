# Fairness Criteria Evidence & Compatibility Reports

This directory stores evidence reports detailing fairness criteria evaluation, threshold satisfaction, compatibility analysis, and explicit conflict declarations.

## Generated Artifacts

- **`criteria_compatibility_report.json`**: Consolidated JSON report recording selected criteria, observed metrics, configured thresholds, per-criterion status, overall compatibility status, and no-silent-priority flags.
- **`criteria_compatibility_report.csv`**: Tabular summary CSV detailing criterion satisfaction states for academic reporting.
